# Story 1.3: Text Embedding Generation

## Status
Draft

## Story
**As a** data engineer,
**I want** 커밋 메시지와 Diff를 임베딩으로 변환하는 서비스,
**so that** 벡터 검색이 가능한 형태로 데이터를 저장할 수 있습니다.

## Acceptance Criteria
1. Azure OpenAI text-embedding-3-large 또는 e5-large를 사용합니다.
2. 코드와 텍스트 혼합 검색에 최적화된 임베딩이 생성됩니다.
3. 임베딩 생성 과정의 배치 처리가 지원됩니다.
4. 임베딩 메타데이터가 원본 커밋과 연결되어 저장됩니다.
5. 임베딩 품질 검증 메커니즘이 구현되어 있습니다.

## Dev Notes

### Previous Story Insights
[Source: docs/stories/1.2.data-preprocessing.md]
- 커밋 데이터가 전처리되어 구조화된 JSON 형태로 변환됨
- 패키지명, 버전, 에러타입, API 시그니처가 추출됨
- 품질 검증 메커니즘이 구현됨

### Technical Constraints
[Source: docs/prd.md#technical-assumptions]
- **Embedding Model**: Azure OpenAI text-embedding-3-large 또는 e5-large
- **Mixed Search**: 코드와 텍스트 혼합 검색 최적화
- **Batch Processing**: 대용량 데이터 처리
- **Quality Validation**: 임베딩 품질 검증

### Embedding Service Architecture
[Source: docs/prd.md#technical-assumptions]
```
Embedding Service:
├── Input: Structured Commit Data
├── Text Processing:
│   ├── Commit Message
│   ├── Code Diff
│   └── Metadata
├── Embedding Generation:
│   ├── Azure OpenAI API
│   ├── Batch Processing
│   └── Quality Validation
├── Output Storage:
│   ├── Vector Database
│   ├── Metadata Mapping
│   └── Index Optimization
```

### File Locations
- 임베딩 서비스: `embedding-service/src/`
- 모델 통합: `embedding-service/src/models/`
- 배치 처리: `embedding-service/src/batch/`
- 품질 검증: `embedding-service/src/validation/`

### Embedding Data Schema
[Source: docs/prd.md#functional-requirements]
```json
{
  "embedding_id": "string",
  "commit_id": "string",
  "embedding_vector": "float[]",
  "text_content": "string",
  "code_content": "string",
  "metadata": {
    "model_version": "string",
    "generated_at": "datetime",
    "quality_score": "float",
    "dimensions": "integer"
  }
}
```

## Testing

### Testing Standards
- **Unit Testing**: 임베딩 생성 및 검증 테스트
- **Integration Testing**: Azure OpenAI API 연동 테스트
- **Performance Testing**: 배치 처리 성능 테스트

### Specific Testing Requirements for This Story
- Azure OpenAI 임베딩 모델이 올바르게 작동하는지 확인

- 배치 처리가 효율적으로 작동하는지 확인
- 임베딩 메타데이터가 원본 커밋과 올바르게 연결되는지 확인
- 임베딩 품질 검증 메커니즘이 올바르게 작동하는지 확인
