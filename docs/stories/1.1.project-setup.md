## Story

5. README.md와 개발 가이드가 작성되어 있습니다.

## Testing

### Testing Standards
- **Test Framework**: Jest with TypeScript support
- **Test Location**: Each service should have its own `__tests__` directory
- **Test Naming**: `*.test.ts` or `*.spec.ts`
- **Coverage**: Minimum 80% code coverage for new code
- **Test Types**: Unit tests for individual functions, Integration tests for service interactions

### Specific Testing Requirements for This Story
- Monorepo 구조가 올바르게 설정되었는지 확인
- TypeScript 컴파일이 모든 서비스에서 성공하는지 확인
- ESLint/Prettier 규칙이 올바르게 적용되는지 확인
- Git hooks가 올바르게 설정되었는지 확인
- 각 서비스의 package.json이 올바르게 구성되었는지 확인
