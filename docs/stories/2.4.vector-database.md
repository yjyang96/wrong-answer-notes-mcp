### Technical Constraints
[Source: docs/prd.md#technical-assumptions]
- **Vector Database**: ChromaDB (로컬 파일 기반)
- **Hybrid Search**: 텍스트 + 벡터 유사도 검색
- **Storage**: 로컬 파일 시스템 기반 저장
- **Performance**: 검색 응답 시간 1초 이내 (로컬 환경)

### ChromaDB Architecture
```
ChromaDB Local Setup:
├── ChromaDB Instance:
│   ├── Collections (컬렉션)
│   ├── Embeddings (벡터 저장)
│   ├── Documents (텍스트 저장)
│   └── Metadata (메타데이터)
├── Data Storage:
│   ├── ./chroma_db/ (로컬 디렉토리)
│   ├── Embedding Vectors (3072차원)
│   ├── Text Content (커밋 메시지 + diff)
│   └── Metadata (분류, 패키지명 등)
├── Search Capabilities:
│   ├── Vector Similarity Search
│   ├── Text Search (문서 내용)
│   ├── Metadata Filtering
│   └── Hybrid Search (벡터 + 텍스트)
└── Monitoring:
    ├── Collection Statistics
    ├── Query Performance
    └── Storage Usage
```

### ChromaDB Collection Schema
```python
# ChromaDB Collection Structure
collection_schema = {
    "name": "commit_embeddings",
    "metadata": {
        "hnsw:space": "cosine",  # 유사도 측정 방식
        "hnsw:construction_ef": 200,
        "hnsw:M": 16
    }
}

# Document Structure
document = {
    "id": "emb_3957c715_1758248512853_e620e87f",
    "embedding": [0.1, -0.2, 0.3, ...],  # 3072차원 벡터

    "metadata": {
        "commit_id": "3957c71530c09bcc2d1ff0876be1a1ca52247255",
```

## Implementation Details

### ChromaDB Setup Requirements
```bash
# Python 패키지 설치
pip install chromadb

# 로컬 ChromaDB 초기화
import chromadb
client = chromadb.PersistentClient(path="./chroma_db")
```

### Key Features
1. **로컬 파일 기반 저장**: `./chroma_db/` 디렉토리에 모든 데이터 저장
2. **자동 백업**: ChromaDB 내장 백업 기능 활용
3. **메타데이터 필터링**: 분류, 패키지명, 에러 타입별 검색
4. **하이브리드 검색**: 벡터 유사도 + 텍스트 검색 조합
5. **성능 모니터링**: 컬렉션 통계 및 쿼리 성능 추적

### Integration with Existing Services
- **embedding-service**: 생성된 임베딩 데이터를 ChromaDB로 마이그레이션
- **data-ingestion**: 원본 커밋 데이터와 메타데이터 연결
- **future search-service**: ChromaDB를 통한 검색 API 제공
